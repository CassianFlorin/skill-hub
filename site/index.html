Three layers. No hidden overwrites.

skill-hub makes the local Skill model explicit before you run update, deploy, or force deploy.

Managed store

Skills in $SKILLHUB_HOME/installed and skillhub.lock are tracked, updated, and rolled back by skill-hub.

Project discovered

Skills found under project roots are visible in list and TUI views, but are not automatically adopted into the managed store.

Runtime copy

Codex, Claude, and Gemini load these copies. Only skillhub deploy changes this layer.

Built for local control first.

Use one CLI to discover packages, manage versions, inspect drift, and deploy into the agent runtime you actually use.

Registry discovery

Browse local and Git-backed Skill registries, then inspect metadata before installing.

Safe updates

Preview update plans with skillhub update --dry-run and roll back managed copies when needed.

Runtime deploy

Copy selected Skills into Codex, Claude, or Gemini and use status checks to spot missing or drifted copies.

Terminal UI

Open skillhub tui to browse local Skills, catalog results, deployment status, and operation logs.

Catalog export

Publish static marketplace snapshots with searchable package metadata for teams or public catalogs.

Multilingual help

Command help is available in English, Simplified Chinese, and Traditional Chinese.

Install to deploy in four steps.

The core workflow stays terminal-native and auditable.

1. Initialize Set up registries and local state.
2. Discover Search catalog entries and inspect package metadata.
3. Install Track versions, source refs, checksums, and history.
4. Deploy Copy managed Skills into runtime directories.
